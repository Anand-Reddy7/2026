## 1. What is LangChain?
"LangChain is an open-source framework used to build applications using Large Language Models.
It provides ready-to-use components to connect LLMs with external tools, APIs, databases, and RAG systems.
For example, in our Kubernetes AI project, we use LangChain to integrate the OpenAI model with Kubernetes tools and a RAG knowledge base, so the agent can retrieve information and troubleshoot application issues."

## 2. What is LangGraph?
"LangGraph is an orchestration framework used to build stateful AI agents and multi-agent workflows.
It allows us to define workflows using nodes and edges, manage state between steps, implement conditional routing, retries, loops, and human-in-the-loop approvals.
For example, in our Kubernetes AI project, we use LangGraph to coordinate multiple agents, such as the Supervisor Agent, Insight Agent, and Automation Agent, to investigate application failures and perform controlled remediation."

## 3. What is MCP?
"MCP stands for Model Context Protocol. It is an open standard that allows AI applications to connect with external tools and data sources through a standardized interface.
Instead of writing separate custom integrations for every AI application, we can expose capabilities through an MCP server, and MCP clients can discover and use those capabilities.
For example, in our Kubernetes AI project, we use an MCP server to expose Kubernetes operations such as getting pod status, fetching logs, and checking cluster events. Our AI agent accesses these tools through an MCP client."

## 4. What is RAG?
"RAG stands for Retrieval-Augmented Generation. It is a technique that allows an LLM to retrieve relevant information from external knowledge sources before generating an answer.
Instead of depending only on the model's training knowledge, RAG provides additional context from our documents or knowledge base. This helps generate more accurate, relevant, and grounded responses.
For example, in our Kubernetes AI project, we store troubleshooting runbooks in a Qdrant vector database. When an application fails, RAG retrieves the relevant runbooks and provides them to the LLM to help identify the root cause and recommend a solution."

Technology	Simple meaning

LangChain	Connects LLMs with tools, data, and other components.
LangGraph	Controls agent workflows, state, and execution.
MCP	Standardizes how AI applications access external tools and data.
RAG	Retrieves relevant knowledge and gives it to the LLM before answering.
