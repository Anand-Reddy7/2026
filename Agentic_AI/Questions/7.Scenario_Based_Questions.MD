# Golden Dataset — KubePilot AI | Interview Preparation + Practical Implementation

A Golden Dataset (Golden Test Set) is a curated collection of test cases containing inputs, expected outcomes, and evaluation criteria that we use to measure the quality, correctness, safety, and reliability of an AI application.

In your KubePilot AI multi-agent platform, we can use a Golden Dataset to evaluate:

- RAG quality: Did the Insight Agent retrieve the correct Kubernetes runbook and provide an accurate answer?
- Agent routing: Did the Supervisor Agent select the appropriate specialized agent?
- Tool selection: Did the Automation Agent choose the correct MCP tool?
- Guardrails: Did the system block unauthorized operations and request approval for sensitive actions?
- Reliability: Did the agent behave correctly when a tool failed or returned incomplete information?
