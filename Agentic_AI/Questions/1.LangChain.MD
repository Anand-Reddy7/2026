## 1. What is LangChain?
LangChain is an open-source framework used to build LLM-powered applications. It provides ready-to-use components to integrate LLMs with external tools, APIs, databases, and RAG systems.
Example: In our Kubernetes AI project, we use LangChain to connect the OpenAI model with Kubernetes tools and a RAG knowledge base for troubleshooting.

## 2. What business problems have you solved using LangChain?
We use LangChain to automate Kubernetes troubleshooting by integrating LLMs with Kubernetes tools and RAG knowledge bases.
Business value: Reduced manual investigation effort, faster incident diagnosis, and controlled release automation.

## 3. What is the difference between LangChain and LangGraph, and when would you choose each?
LangChain provides components for integrating LLMs with tools, APIs, and RAG systems.
LangGraph is used to orchestrate stateful agent workflows with nodes, edges, conditional routing, retries, checkpointing, and human-in-the-loop approvals.
When to use:
- LangChain: For simple LLM applications, tool integration, and RAG pipelines.
- LangGraph: For complex workflows involving multiple agents, state management, retries, and human approvals.

## 4. What is the ReAct reasoning/action loop?
ReAct stands for Reasoning and Acting.
It is an agent design pattern where the LLM decides which action to take, calls a tool, observes the result, and repeats until the task is completed.
Flow: Reason → Act → Observe → Repeat → Final Answer.

## 5. How does an agent perform tool calling, and how do you make tool selection more deterministic?
In tool calling, we define tools with names, descriptions, and input schemas and bind them to the LLM.
The LLM selects the appropriate tool based on the user request, the framework executes it, and the result is returned to the LLM.
To improve deterministic tool selection, we use clear tool descriptions, strict input schemas, restricted tool access, low temperature, and LangGraph conditional routing.
Remember: Low temperature improves consistency but does not guarantee deterministic behavior.

## 6. What other AI agent frameworks do you know?

Apart from LangChain and LangGraph, I am familiar with CrewAI, AutoGen, OpenAI Agents SDK, Google ADK, and Semantic Kernel.

These frameworks are used to build AI agents, integrate tools, and coordinate multi-agent workflows.

In our Kubernetes AI project, we chose LangGraph because it provides better control over workflow orchestration, state management, retries, and human-in-the-loop approvals.
